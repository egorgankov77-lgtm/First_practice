# Экспертная оценка безопасности

## 1. Область анализа

Исследован проект `basic-flask-template-master`.

Проведены два вида проверки:

1. **Bandit** — статический анализ Python-кода.
2. **Nikto 2.1.5** — проверка локально запущенного Flask-приложения по адресу `http://127.0.0.1:5000`.

Сканирование Nikto выполнялось только против локального тестового сервера `127.0.0.1`.

## 2. Результаты Bandit

Bandit просканировал 30 строк Python-кода.

Результат:

- High: 0
- Medium: 0
- Low: 0
- Files skipped: 0
- No issues identified.

По результатам Bandit проблем безопасности в проанализированном Python-коде не обнаружено.

## 3. Результаты Nikto

### 3.1. Отсутствует X-Frame-Options

Nikto сообщил:

`The anti-clickjacking X-Frame-Options header is not present.`

Экспертная оценка: **средний приоритет для устранения**.

Рекомендация: настроить защиту от встраивания страницы в frame. В зависимости от архитектуры следует использовать соответствующую политику Content-Security-Policy (`frame-ancestors`) и/или X-Frame-Options.

### 3.2. Потенциально интересный /console

Nikto сообщил:

`OSVDB-3092: /console: This might be interesting...`

Экспертная оценка: **требует проверки**.

Важный контекст: приложение было запущено с Flask debug mode, поскольку в `app.py` используется `app.run(debug=DEVELOPMENT_ENV)` при `DEVELOPMENT_ENV = True`.

Рекомендация: проверить, доступна ли debug console, и не использовать Flask debug mode в production.

### 3.3. Информация о сервере

Nikto определил:

`Werkzeug/3.1.9 Python/3.14.4`

Экспертная оценка: **информационная находка**.

Рекомендация: оценить необходимость раскрытия сведений о серверном стеке в рабочем окружении и минимизировать избыточное раскрытие версий там, где это возможно.

## 4. Общая оценка

Bandit не выявил проблем в проанализированном Python-коде.

Nikto выявил два пункта, требующих внимания: отсутствие `X-Frame-Options` и потенциально интересный `/console`, а также информационное раскрытие версии серверного ПО.

Наиболее важная практическая рекомендация для данного проекта — не использовать debug mode при реальном развёртывании приложения и проверить конфигурацию security headers.

## 5. Ограничения анализа

- Bandit проверяет Python-код и не заменяет анализ зависимостей, конфигурации инфраструктуры или веб-сервера.
- Nikto проверял только локальный Flask development server на `127.0.0.1:5000`.
- Формулировка `/console: This might be interesting` не является сама по себе доказательством уязвимости; необходима отдельная проверка.
- Nikto не присвоил этим сообщениям уровни severity, поэтому уровни в CSV являются экспертной классификацией для датасета.

## 6. Правовые и организационные ограничения

Сканирование проводилось только против локального тестового объекта, находящегося под контролем исполнителя. Внешние системы и чужая инфраструктура в рамках этого анализа не сканировались.
